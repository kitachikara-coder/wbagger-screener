## 修正方針

### A-1. S高種別の判定（`recent_stop_high()` の戻り値に追加）

S高日のバー（**調整前の生値 `H` と `C`** を使う。`UL` は生値ベースのフラグなので調整後と混ぜない）で判定する。

```python
# 戻り値に "sh_kind" を追加: "張り付き" | "一時"
#   張り付き: S高日の C >= H （終値が当日高値と同値＝引けまで上限）
#   一時    : C < H
```

- **同値判定は浮動小数の等値比較を避け、`C >= H - 1e-9` とする**（呼値は整数〜小数1桁だが、AdjFactor を経由しない生値でも安全側に）
- `H` または `C` が欠損（無取引日など）の場合は **`None`（画面は「—」）**。「一時」に倒さない
- **しきい値（例: 高値の99.5%以上なら張り付き扱い）は導入しない。** 恣意的な閾値は検証していない。
  厳密に「終値＝高値」だけを張り付きとする

### A-2. 層Aに「S高種別」列を追加

- 位置：**「ストップ高日」列のすぐ右**
- 表示：`張り付き` / `一時` / `—`
- **色分けはしてよいが、優劣を示唆する配色にしない**（例: どちらも同系色の淡いバッジ。緑＝良い/赤＝悪い は付けない）。
  どちらが有利かは**未検証**（B群）
- フィルタ：市場フィルタと同じ形で「すべて／張り付き／一時」を追加。**既定は「すべて」**
- ソート：ヘッダクリックでソート可能にする。**既定ソートは変えない**（S高日が新しい順 → 枯れ比が低い順）

### A-3. 注記に1行足す

既存の注記ブロックに、次の趣旨を1行（**文言に「業種」の2字を連続で含めないこと**。親プロジェクトのE2E検査と同じ地雷を避ける）。

> S高種別 = S高日の終値が当日高値と同値なら「張り付き」、下回れば「一時」。`UL` は上限に**触れた**フラグで、
> 引けまで買われ続けたことを意味しない。どちらが有利かは未検証【推測】。

### A-4. 手入力材料の反映確認（コード変更なし・確認のみ）

Cowork が `manual/` に6件（`593A` `6522` `3907` `607A` `462A` `4170`）を追加済み。
**ローダが正しく拾い、層Aの「材料分類」列と層Bのカードに出ることを実データで確認**すること。
特に次の3点：

1. `6522` は `earnings_date: "2026-10-15"` / `earnings_date_confirmed: true` → **「確定」表示**になるか
2. `593A` `4170` などは `earnings_date` キー自体が無い → **「—」**で落ちないか
3. `material` の複数行ブロック（`|`）と `★` を含む文字列が崩れずカードに出るか
