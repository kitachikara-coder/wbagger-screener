## 背景 — なぜ必要か

柴田氏の実運用フローは次の7段階で、ダッシュボードの役割は **①〜③の絞り込み**と、**④の判断前に「チャートで見えない情報」を揃えること**。

1. 直近でストップ高になった銘柄の材料を調べる
2. 「下落した後に再上昇しそうな銘柄」を候補に残す
3. 押し目を待つ
4. 大引け間際に日足を確認し、形状から需給を読む
5. 反転しそうなら大引けで少量買う
6. 翌日、日中足が上昇傾向なら追加で買う

**現行 `screener.py` は「当日の初動（値上がり率≥5% or 当日S高）」しか見ていない**ため、②③（S高した後、押し目が進行中の銘柄）が画面に出てこない。S高翌日以降は前日比が5%未満に落ちるので候補から消える。ここが最大のギャップ。

### 本人決定事項（2026-09-12）
| 項目 | 決定 |
|---|---|
| 手法 | **A: 大引け判断＋翌日追加の分割エントリー**で一本化。買い下がり（ナンピン）は不採用（-7%機械損切りと矛盾するため）。B群として保留 |
| 需給データ | **J-Quants を Light → Standard に変更**し `/markets/margin-interest` を自動取得 |
| 判断ログ | **(a) リポジトリ内JSON**（`docs/data/decisions.json`） |

### 目的（取り違えないこと）
**「買うべき」と自動判定させない。** 「この銘柄を今、自分なら買うか？」を本人が判断するための材料を揃えるのが目的。
したがって **合成スコアや◎○△の総合判定は作らない／既存のものは外す**。

## 現状のギャップ（コード特定済み）

### G1. S高後の押し目が候補に入らない（最重要）
`screener.py:235 build_shortlist()` は **当日の1日分**しか見ていない。
```python
change = (close - pclose) / pclose * 100
stop_high = str(row.get("UL")) == "1"
if change >= crit["change_pct_min"] or stop_high:   # ← 当日のみ
```
→ S高の翌日以降（=押し目局面）は抽出されない。**直近20営業日内にS高があった銘柄**を母集団にする必要がある。

### G2. 信用残のフィールド名が誤り（取得できていない）
`screener.py:396`
```python
for key in ("LongMarginTradeVolume", "LongVo", "Long", "LongMargin", "LMgn"):
```
→ v2 の実名は **`LongVol` / `ShrtVol`**。現在は全銘柄 `margin_long_k: null`（実データで確認済み）。
加えて Light では 403 のため、**Standard 切替後に正しい列名で実装**する。

### G3. 「判定◎○△」が自動判定になっている
`screener.py:408 label()` が `初動入口◎ / 押し目待ち○ / 監視△ / 除外` を返し、`render()` の既定ソートキーにもなっている（`screener.py:435`）。
→ 目的（自動判定させない）と矛盾。**事実ラベルに置換して撤去**する。

### G4. 一覧の列がチャートで分かる情報で埋まっている
`screener.py:499-500` のヘッダ：`P.O.` `MACD` `出来高倍` `自己資本` `増益` は、チャートを見れば分かる／一覧の一次判断には不要。→ 層Bへ移動。

### P1. 層A — ふるい一覧

#### 母集団の変更（G1）
新関数 `recent_stop_high(jq, uni_codes, target, window=20) -> Dict[str, Dict]` を追加。
- `target` から遡って**直近 `window` 営業日**の各日を `bars_by_date()` で取得（**追加 +20リクエスト**）
- `UL=="1"` の銘柄について `{code: {"sh_date","sh_vol","sh_close"}}` を記録し、**最新のS高日**を採用
- 戻り値のコードが層Aの母集団。当日S高（`sh_date == target`）も含む＝手順①②の「材料を調べる対象」として一覧に出る

> 当日S高した銘柄は押し目がまだ無いので「高値からの日数=0・下落率≈0」として表示される。
> **S高直後と押し目進行中を同じ表で並べ、日数・下落率・枯れ比の列で本人が段階を読み取る**設計。

#### 列（確定）
| 列 | 定義 | 実装メモ |
|---|---|---|
| コード / 銘柄 / 市場 | 既存 | `market_universe()` |
| **ストップ高日** | 直近20営業日内の最終S高日（YYYY-MM-DD） | `recent_stop_high()` |
| **高値からの日数** | S高日以降の最高値（`AdjH` 最大）を付けた日から当日までの**営業日数** | 同一銘柄の日足配列の添字差 |
| **高値からの下落率** | `当日AdjC ÷ 期間最高値 − 1`（%） | 期間 = S高日〜当日 |
| **出来高枯れ比** | `当日AdjVo ÷ S高日AdjVo`（%）。**5日平均版も併記**（直近5日平均 ÷ S高日） | **最重要列** |
| **売買代金20日平均(億)** | `mean(AdjC × AdjVo, 20日)` ÷ 1e8 | 流動性ゲート |
| 株価(終値) / 前日比 | 既存 | |
| 時価総額(億) | 既存（`ShOutFY − TrShFY` × 終値） | |

| **材料分類** | 手入力（未入力は「未」） | P2のYAMLから読む |
| タブー | 既存（自己資本≤30%・営業CF3期連続赤字） | 事実の足切りなので残す |

- `P.O.` / `MACD` / `出来高倍(20日平均比)` / `自己資本` / `増益` → **層Bへ移動**
- 既定ソート：**S高日が新しい順 → 出来高枯れ比が低い順**

市場（グロース／スタンダード）／下落率レンジ／決算跨ぎ除外（決算まで N営業日以内を隠す）／材料分類／検索。
